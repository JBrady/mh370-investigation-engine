# Vision

`MH370-investigation-engine` exists to support rigorous, public-evidence analysis of MH370 using inspectable engineering contracts rather than narrative reasoning.

The repository should enable a reviewer to see:

- which public source was used
- which concrete artifact was extracted
- which claims were authored from that artifact
- which constraints were applied
- which scenario was evaluated
- why a compatibility result was produced

The repository should not attempt to:

- invent new hypotheses
- rank narratives through opaque scoring
- substitute prose summary for structured evidence
- store evidence without explicit provenance
