# Glossary

- Source: a public publication or record set used as an evidentiary origin.
- Artifact: a concrete file, annex, table, transcript, image, or other extractable unit tied to a source.
- Claim: an atomic statement linked to a source and artifact.
- Claim link: an explicit relationship between claims such as support or contradiction.
- Constraint: a first-class bounded condition used during scenario evaluation.
- Scenario: an explicit explanation framework that references claims and constraints.
- Derived view: a generated analytical artifact such as a timeline or compatibility report.
- Compatibility band: a non-probabilistic evaluation label derived from visible factors.
- Assumption load: the amount of unsupported scenario structure required to keep a scenario viable.
